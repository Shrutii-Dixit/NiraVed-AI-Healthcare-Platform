# Implementation Roadmap

The project is in planning and design. Milestones below are proposed, have no fabricated dates, and do not imply that code or results exist.

| Phase | Work | Status | Exit evidence |
|---|---|---|---|
| 0. Scope and requirements | Confirm two targets, requirements, faculty decisions, team allocation | In progress / approval pending | Agreed scope and named role allocation |
| 1. Research and data | Review literature; shortlist datasets; verify provenance, labels, and terms | Planned | Verified citations and data register |
| 2. Heart study | EDA, leakage-safe preprocessing, baseline, candidates, evaluation, explanation review | Planned | Reproducible heart experiment report |
| 3. Stroke study | EDA, imbalance-aware pipeline, baseline, candidates, evaluation, explanation review | Planned | Reproducible stroke report including PR metrics |
| 4. Integration | Agree schemas; implement proposed API and UI after models are ready | Planned | Reviewed interfaces and integration evidence |
| 5. Validation and reporting | Run available tests, review safety and privacy, prepare final report/presentation | Planned | Recorded commands, actual results, and reviewed deliverables |

Update status only when the stated evidence exists. Dataset performance does not equal external generalization or clinical validation. Cost estimation, hospital recommendations, insurance guidance, OCR, and extra disease modules remain future scope.
