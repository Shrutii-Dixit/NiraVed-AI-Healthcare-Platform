# Research Documentation

This directory holds verified literature notes, research gaps, and experiment reports. There are no completed experiments or verified domain-paper findings currently recorded.

Use the [literature review template](literature-review-template.md). Search before adding a paper to avoid duplicates. Verify metadata against the publication itself or an authoritative publisher/repository record. Keep the authors' stated conclusions separate from the team's interpretation and relevance to NiraVed. Record dataset version, methods, split protocol, metrics, limitations, and code revision with any future experiment report. Never commit restricted data or identify patient records.
